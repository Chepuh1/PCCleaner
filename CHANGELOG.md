# Changelog

## 0.11.0 — 2026-11-06

First public release.

- Cleanup: temp files, browser cache, Recycle Bin, whitelist, special files
- Performance: live CPU / GPU / RAM, memory cleanup, game mode
- File manager: uninstall programs and Store apps, one-click `.zip` backup of files and configs
- 5 themes and 2 languages (English / Russian), switched instantly without restart
- Windows 11 look: dark title bar, rounded corners, accent window border, app icon
- Enter and leave administrator mode from the app
- About page with feedback links and "Copy system info"
